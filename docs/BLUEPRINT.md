# Blueprint summary
Source: `time_table.docx`. Hard rules: no class/teacher double-booking; exact weekly frequencies;
primary ends 12:00, senior 14:00; zero period & lunch reserved; weekly activity block fixed;
teacher max 5 periods/day; substitutes only from free teachers.
Soft rules: substitute = most free periods that day; spread subjects across week; balance specialists.
Stack: FastAPI + OR-Tools CP-SAT + React + PostgreSQL + Docker.
